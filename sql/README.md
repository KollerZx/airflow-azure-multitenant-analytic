# Scripts auxiliares para manutenção do pipeline

Este diretório contém scripts úteis para operação e manutenção do pipeline.

## Scripts disponíveis

### check_views_status.sql

Verifica o status atual das views materializadas e última atualização.

### refresh_all_views.sql

Executa refresh manual de todas as views (útil para testes).

### performance_stats.sql

Consulta métricas de performance do ETL.
